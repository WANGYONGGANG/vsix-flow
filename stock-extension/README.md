# StockExt VSCode 扩展

## 功能
- 实时行情、K线、自选股管理
- AI 智能分析（支持 OpenAI 协议任意服务）
- 公式指标编写与绘制
- 快讯、新闻、板块分析

## 安装
1. 下载 `.vsix` 文件
2. VSCode 中按 `Ctrl+Shift+P` → `Extensions: Install from VSIX...`
3. 选择下载的 `.vsix` 文件

## 配置
- **代理端口**：本地代理服务端口（默认 1890）
- **AI 模型**：在设置中配置 API Key 和模型地址

## 使用
- 打开侧边栏 `StockExt` 面板
- 支持概况、自选、AI助手、资金、新闻等标签页
- 公式管理：点击K线图右上角"fx"按钮
